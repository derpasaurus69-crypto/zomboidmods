# Portal v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows companion app where a player types a real place, picks a size preset, presses Generate & Play, and gets an installed Project Zomboid B42 map mod of that place, plus a Publish-to-Workshop helper.

**Architecture:** Portal is a small Flask app on localhost. All KnoxMap work happens in a separate process: Portal's `engine/runner.py` runs under KnoxMap's own venv Python, drives KnoxMap's Flask app in-process through `app.test_client()` (proven in the Phase 0 spike: search â†’ `/api/generate` â†’ `/api/buildings` â†’ `/api/compile` + `/api/compile-status` â†’ package), and streams JSON-lines events on stdout. `EngineAdapter` is the only Portal code that starts or reads that process.

**Tech Stack:** Python 3.13 (Portal venv: flask, pillow, pytest, pyinstaller); KnoxMap 1.8.4 at `D:\modding\pz-portal-engine\knoxmap` with its own `.venv`.

**Spec:** `docs/superpowers/specs/2026-11-03-pz-portal-design.md`

## Global Constraints

- Build 42 only; Windows only in v1.
- Scale fixed at 1 m/tile (`metersPerTile: 1`).
- Presets (square side â†’ compiled cells at 256 m/cell, counting the extra row and column a square overlaps because it never lines up with the cell grid â€” measured 25 for 1 km in the spike): `downtown` 1.0 km â†’ 25; `town` 3.0 km, clipped to the place outline when one exists â†’ â‰¤169; `city_core` 5.0 km â†’ â‰¤441.
- Mod ID: `portal_<name>_<region>_<preset>`, ASCII `[a-z0-9_]`, â‰¤ 60 chars (KnoxMap truncates names to 60 and allows only `[A-Za-z0-9_-]`).
- Supported KnoxMap versions: exactly `{"1.8.4"}` (read with `knoxlog.version()`); anything else refuses to generate unless `allow_untested_engine` is set in settings.
- Portal never downloads, bundles or runs KnoxMap's installer; it only runs KnoxMap's existing venv Python on Portal's runner.
- Nothing in `~/Zomboid/mods` is written except by `Installer.install`'s final rename; never overwrite a mod without Portal's `.portal.json` marker.
- Every installed mod and Workshop folder contains `ATTRIBUTION.txt` with "Â© OpenStreetMap contributors".
- Search runs only on an explicit submit (Enter/button), never on keystrokes.
- Bulky data stays off C: where possible: KnoxMap output lives in KnoxMap's `output/` (D:); Portal's library index is JSON only.
