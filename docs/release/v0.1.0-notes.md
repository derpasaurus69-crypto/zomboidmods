# Portal 0.1.0

First public release. Type a real place, play it in Project Zomboid Build 42.

## What it does

- Search any town on OpenStreetMap, pick **Downtown** (1 km), **Town**
  (up to 3 km, clipped to the real boundary) or **City core** (5 km), and
  press **Generate & Play**. The town is installed as a map mod.
- Each town gets a poster in the Mods list, its own picture on the New Game
  spawn screen, and spawn points in homes near the centre.
- **Start at an address:** type a street address and you begin in that house.
- **Add buildings OpenStreetMap is missing:** fills thinly mapped towns from
  Microsoft's building footprints.
- **Publish to Workshop...** lays a town out for the game's Workshop uploader,
  with the credits already in the description.

## You need

- Windows, Project Zomboid on Build 42.
- [KnoxMap 1.8.4](https://github.com/spytheeuclidean-a11y/knoxmap), installed
  separately with its `Setup.bat`. Portal finds it in the usual places or asks
  for the folder.

## Tested

- Singleplayer on one Windows 11 PC: Bardstown, Kentucky and Schuylkill
  Haven, Pennsylvania, both at the Town size. Checked: Mods list and poster,
  spawn screen, spawning, streets and buildings, shop loot, world map street
  names.
- Not tested: multiplayer, the City core size, other PCs.
